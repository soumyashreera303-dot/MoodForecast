# ☁️ Mood Forecast

A cute little web page that gives you a weather forecast for your mood.

Answer 3 quick questions and a friendly cloud tells you today's "weather", with a funny chance line and a kind tip.

## How it works

1. You answer 3 questions: **energy**, **sleep**, and **stress**.
2. Each answer gives 1 to 3 points.
3. The total score picks your weather:

| Score | Weather |
|-------|---------|
| 9 | ☀️ Sunny |
| 8 | 🌈 Rainbow Day |
| 7 | ⛅ Partly Cloudy |
| 6 | 🌫️ Foggy Brain |
| 5 | 🌦️ Light Drizzle |
| 3 to 4 | ⛈️ Stormy |

The cloud changes its color and face to match your mood.

## Run it

No install needed. It's one file.

1. Download or clone this repository.
2. Double-click `index.html` to open it in your browser.

Or open the folder in VS Code and use the **Live Server** extension.

## Make it yours

Open `index.html` and try these:

- Change the questions in the `Q` list
- Rename weathers or edit the tips in the `W` list
- Change the colors at the top of the `<style>` section

## Built with

Plain HTML, CSS, and JavaScript. No libraries. The font is [Fredoka](https://fonts.google.com/specimen/Fredoka) from Google Fonts.
